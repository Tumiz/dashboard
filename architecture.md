This is a development guide that code agent should follow

1. The dashboard is not only a dashboard to show historical data but also a dashboard to show predicted gold prices, including predicted gold price next month but also gold price three months from now

2. The xau_predictor.py should save predictions to a json file that can be read and shown by index.html

3. Significant events related to gold prices are stored in xau_events.js, only breaking news, not a document or conclusion articles
